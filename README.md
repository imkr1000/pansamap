# 판사맵 MVP

판사맵은 공개된 법관 인사자료, 판결문, 재판부 정보를 시민이 쉽게
확인할 수 있도록 정리하는 사법정보 접근성 프로젝트입니다.
초기 버전은 리뷰, 별점, 댓글 기능을 제공하지 않습니다.

이 저장소는 공개자료 기반 법관 정보 지도 v0 프로토타입입니다.
법관·법원·판결 정보, 출처, AI 요약 고지, 정정 요청, 운영정책 흐름을
검증합니다.

## 실행

빌드 도구가 필요 없는 정적 앱입니다.

```bash
npx serve .
```

또는 `index.html`을 브라우저에서 직접 열어 확인할 수 있습니다.

## 포함된 화면

- 서비스 소개 페이지
- 법원 지도형 첫 화면
- 법관 검색과 상세 페이지
- 법원별 목록과 상세 페이지
- 판결문 링크와 AI 요약 고지
- 정정 요청 폼
- 운영정책 / 개인정보 / AI 요약 정책 초안

## 데이터

`data/sampleData.js`의 법관·판결 데이터는 실존 인물 평가가 아닌 UI
검증용 가상 데이터입니다. 실제 공개 데이터 입력 전에는
`docs/policy.md`의 운영 원칙과 출처 검증 절차를 먼저 적용해야 합니다.

## 향후 과제

- Next.js + Supabase/PostgreSQL 전환
- 운영자 인증
- `Judge`, `Court`, `Appointment`, `CaseDocument`, `Source`, `CorrectionRequest`, `AuditLog` 테이블 생성
- 판결문 원문 해시 검증
- AI 요약 생성/검수 파이프라인
- 공개 전 법률 표현 리스크 리뷰
